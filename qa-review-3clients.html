二、逐客户深度拆解

🔴 客户1：蓝山 — D级（27/60）

客户画像：男56岁，175cm/147斤，餐后血糖23.8，严重痛风手术史，长期饮酒，右脚掌麻木2年，间断服二甲双胍

对话节奏：Day1 16:32破冰 → 28分钟密集互动（客户配合度极高）→ Day2 09:04客户主动说"你好"→ 11:48对话破裂

🔴 P0 致命问题 ×4

1. 诊断越界 + 恐惧营销双重打击
"您知不知道血糖高最怕什么" → "脚麻可能是血糖高引起的末梢循环不好" → "血糖高不可怕，可怕的是控制不好引起的并发症发生……不是吓唬您"

客户血糖23.8，脚麻——这是真实健康风险。但顾问应立即建议就医，而非利用恐惧铺垫产品。

2. 客户说"买完了"→牛头不对马嘴的回复

客户："买完了" + "我去医院了，大夫让我扎胰岛素"
顾问："医生不负预防并发症，只负责治疗，现在医院的病人多，都是越治问题越多……益衡和轻路就可以帮助您预防并发症"

致命一击：当面贬低医生——客户正在医院遵医嘱打胰岛素，这话等于说客户听医生的错了。

3. 客户爆发："这么唠嗑有意思吗"
整段对话的审判词。客户隔4小时后用这句话终结，顾问还在发文件。

4. 产品话术越界
"用一段时间……医生会让您少用药，甚至停药"——益衡+轻路是食品，不能承诺疗效。

🟠 P1 严重问题 ×2

5. 用户画像误判：56岁、血糖23.8、痛风严重、脚麻2年——这是急需医疗干预的患者，不是"买保健品预防"的对象。

6. 缺"就医前置"话术：面对血糖23.8+脚麻2年，第一反应应该是建议就医，而非推产品。

4. 售后跟进有节奏：D5推荐→D6温和催单→D7跟进食谱。不密集、有递进、有温度。

5. 专业边界清晰：看到二甲双胍说"医生应该是想改善胰岛素分泌的问题"——认可医生判断，不越界。
